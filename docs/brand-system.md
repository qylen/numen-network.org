# Brand & Visual System — Numen Network

## 1. Aesthetic Concept
**Matter + Computation + Geometry + Networks + Proof + Identity.**
Visual language inspired by scientific visualization, deep-space observatories, high-precision engineering tools, and computational geometry. Restrained, futuristic, minimal, and highly trustworthy.

## 2. Color Tokens

### Dark Theme (Default)
- `--bg`: `#0d0e12` (Obsidian Deep Space)
- `--bg2`: `#15171e` (Subsurface Slate)
- `--bg3`: `#1c1f2a` (Elevated Panel)
- `--ink`: `#f0f3f9` (Primary Monospaced White)
- `--lead`: `#a0aabf` (Secondary Technical Text)
- `--body`: `#828ca0` (Body Text)
- `--dim`: `#5c6476` (Muted Annotation)
- `--accent`: `#22d3ee` (Spectral Cyan / Precision Laser)
- `--accent-glow`: `rgba(34, 211, 238, 0.15)`
- `--line`: `#202430` (Structural Grid Line)
- `--line2`: `#2a3040` (Card Border)

## 3. Status Badge Palette & Standards
- `LIVE`: Green accent `#10b981` (Verified operational)
- `AVAILABLE`: Cyan accent `#06b6d4` (Verified feature/docs)
- `TESTNET`: Amber accent `#f59e0b` (Explicitly testnet)
- `IN DEVELOPMENT`: Indigo accent `#6366f1` (Confirmed work in progress)
- `UPCOMING`: Slate accent `#64748b` (Planned)
- `INFORMATION TO BE CONFIRMED`: Neutral gray `#475569` (Pending confirmation)

## 4. Typography Hierarchy
- Primary Font: `Space Grotesk` (Headings, Section Titles, Hero)
- Technical Font: `IBM Plex Mono` (Data metrics, code snippets, formulas, status labels)
