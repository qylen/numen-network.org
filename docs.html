FAQ

Common questions

What is Numen Network?
A Proof-of-Scan Layer 1 blockchain built with the Polkadot SDK. It combines permissionless PoW block proposal, GRANDPA BFT finality, full EVM compatibility on testnet chain ID 320261, and Spectral3D geometry-based identity.
What exactly is Proof of Scan?
It’s Numen’s proof-of-work. Each nonce deterministically seeds a 3D asteroid mesh; its surface is sampled with 4,096 rays into a 23-dimension spectral signature whose hash must meet the difficulty target to seal a block. Finding seals is hard; verifying them is exact.
Which EVM chain ID should I use?
Use 320261 (0x4e305) for the testnet. Devnet builds use 320262, and 32026 is reserved for future mainnet. Standard Ethereum JSON-RPC means MetaMask, Foundry, Hardhat, viem and wagmi all work unmodified.
Do I need a private key to mine?
No. Mining only needs a payout address. Generate a keypair offline (for example with subkey generate) and pass just the SS58 address to the node via --miner. Invalid addresses make the node refuse to start — intentional.
How do rewards and halvings work?
Each sealed block mints 16 NMN to the miner’s payout account. Every 12,500,000 blocks (~4 years) the reward halves, so total mined issuance converges to 400 million NMN. Orphan blocks earn nothing.
Is there a block explorer?
One is in development. Until it ships, a synced local node is the ground truth — and the website’s network dashboard leaves live figures blank rather than showing stale numbers.
Is Numen live on mainnet?
Not yet. A decentralized public testnet runs at release v0.2.0, where sudo was replaced by Prime — a restricted authority covering runtime upgrades and vetoes only. Mainnet preparation is in development.
Can I register a physical object on-chain today?
Registration is planned, not shipped. Spectral3D identities already power the mining work function, and the library is open source — but applications that own, track or tokenize object identities wait on the planned registry. See the roadmap.
