PoScan · Proof of Scan

The Scan is the Work

Proof-of-Scan replaces arbitrary table hashing with deterministic 3D geometry generation and surface ray sampling. Verifiers re-execute the exact pipeline per seal without storing raw mesh data.

STEP 1 · DERIVE
seed = H(pre_hash ‖ addr ‖ nonce)

Work is bound cryptographically to the current block header and miner payout address. Pre-computation and replay attacks are impossible.

STEP 2 · GROW
asteroid_det(seed, sd=4)

Generates a 2,562-vertex deterministic 3D asteroid mesh using procedural fractional Brownian motion (fBm) noise field recasting.

STEP 3 · SCAN
spectral3d.scan(mesh, 4096)

Casts 4,096 surface rays across the generated mesh to construct a 23-dimension spectral signature array.

STEP 4 · SEAL
s < target → block seal

Quantized spectral dimensions hash into a 256-bit work hash. If it meets the target, the block seal is broadcast.

Difficulty Engine

ASERT Self-Healing Adjustment

Numen uses Absolutely Scheduled Exponential Target (ASERT) difficulty adjustment to prevent oscillation and guarantee immediate network recovery.

next_target = anchor_target × 2^((Δt − 10s · Δh) / 1800s)

Anchor-based schedule calculations eliminate recursive drift and difficulty manipulation. If hashpower drops drastically, difficulty halves every 30 minutes until blocks resume at 10-second intervals.

Spectral3D Library

Shape is Identity

The underlying library behind Proof-of-Scan transforms physical and 3D object geometry into stable cryptographic fingerprints.

Conventional File Hashes

Traditional file hashes break if a single bit or metadata tag changes. The digital hash is detached from the physical asset.

SPECTRAL3D HASH ID

Geometric Shape Hashes

Spectral3D reads rigid spatial surfaces. Re-scanning an object under any scanner orientation or noise threshold produces the exact same HASH ID offline.
