PoScan · The work function

The scan is the work

Instead of hashing until a number is small enough, miners grow deterministic geometry and measure it. Every parameter that defines the puzzle is pinned by the protocol — nothing about the work can be shortcut.

Step 1 · Derive

seed = H(pre_hash ‖ addr ‖ nonce)

Work is bound to the current block header and the miner’s payout address. Pre-computation and replay are impossible by construction.

Step 2 · Grow

asteroid_det(seed, subdivisions)

The seed deterministically grows an asteroid mesh via an icosphere deformed by seeded fBm noise — craters, lobes and all. Same seed, same mesh, always.

Step 3 · Scan

spectral3d::scan(mesh, 4096)

4,096 rays sample the surface into a 23-dimension spectral signature — stable under rotation and pose.

Step 4 · Seal

hash(features) ≤ target ? seal

Quantized dimensions hash against the ASERT-adjusted target. A valid seal enters the block digest and proposes the block.

Pinned parameters

Surface samples per attempt4,096
Spectral dimensions23 quantized
Mesh subdivisionPinned level (no resolution-for-speed trades)
Domain separatorposcan-v1

Why this design holds up

Fine quantization (~1e-6 bucket widths) fills the search space with entropy, killing low-resolution and surrogate shortcuts. Determinism tests in CI assert the same seed reproduces the same mesh across platforms.

Verifiers re-execute the pipeline per seal — no mesh storage required, only the seed and parameters.

Difficulty engine

ASERT self-healing adjustment

Absolutely Scheduled Exponentially Rising Targets: every block’s target is computed independently against a fixed anchor, so difficulty never accumulates drift and the chain recovers cleanly after hashrate shocks.

The formula

pallets/difficulty · asert.rs
next_target = anchor_target
            × 2^((time_delta − target_block_time × height_delta)
                  / halflife)

target_block_time = 10 s
halflife          = 1800 s  (30 minutes)

What it means in practice

No cumulative errorEach block computed fresh from anchor
Natural decayDifficulty halves every ~30 min offline
Outage recoveryAnchor re-bases at the recovery block
Manipulation resistanceTimestamp games can’t compound

If hashpower vanishes, blocks don’t stall for days — targets relax on a fixed half-life until production resumes at the 10-second rhythm.

Spectral3D library

Shape is identity

The same library behind mining converts rigid geometry into stable cryptographic fingerprints — the foundation for physical-object identity.

Conventional

File hashes break

A traditional hash changes when a single bit or metadata tag changes. It identifies a copy of a file, not the physical thing it came from.

Spectral3D

Geometry hashes hold

Spectral3D reads rigid spatial structure. Re-scan an object from any orientation, on any scanner, and the fingerprint resolves to the same identity.
