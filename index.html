The problem

Billions of physical objects move, degrade and change hands every day — and almost none of them can be verified on-chain.

Digital systems verify files, signatures and messages natively. The moment value leaves the screen — a machine, a shipment, a spare part — verification collapses back onto paperwork and trust.

/01

Identity doesn’t survive the real world

A file hash changes when a single bit or metadata tag changes. It describes the copy — never the object itself.

/02

Verification runs through intermediaries

Authenticity and provenance still depend on centralized registries, manual audits and parties you have to trust.

/03

Blockchains are blind to physics

Ledgers verify digital events natively, yet atoms reach smart contracts only through whatever feeds the chain.

Introducing

Proof of Scan

Numen’s native proof-of-work is not arbitrary hash-searching. Each attempt deterministically grows a 3D mesh from a seed, scans its surface with 4,096 rays, and reduces it to a spectral fingerprint. Finding a valid seal is genuinely hard work — verifying one is exact.

Every mining attempt grows an asteroid mesh from a seed, then sweeps its surface with 4,096 sample rays. Subdivision level is pinned by the protocol, so resolution cannot be traded for speed.

Ray measurements resolve into 23 quantized spectral dimensions. Re-scanning the same geometry from any pose yields the same identity — that stability is what makes it useful beyond mining.

Quantized features hash into the work hash. If it meets the ASERT-adjusted target, the seal is valid and proposes a block — hard to find, instant to verify.

Seals anchor blocks; the same machinery anchors objects. Contracts read both through standard EVM JSON-RPC on chain 320261 — Foundry, Hardhat, viem and ethers work unmodified.

With a planned on-chain registry, identities support real-world applications: asset records, custody tracking, tokenization and authenticity checks. Registry functionality is planned — see roadmap.

Mining

Secure the chain. Earn the emission.

Numen mining is CPU-friendly geometric scanning — no ASICs, no stake, no permission. Your keys never touch the mining rig: the node embeds only a payout address in block headers.

Run a node

Grab a prebuilt binary from releases and sync the testnet chain.

Configure payout

Pass an SS58 address with --miner; generate keys offline.

Get tasks

Pull mining_getTask or subscribe for a fresh task every second.

Scan

Grow the seeded mesh and sweep its surface across all cores.

Submit a seal

Return mining_submitSeal when your hash meets target.

Earn rewards

Valid seals author blocks. Rewards accrue to your payout address.

$ ./numen --chain testnet-raw.json --miner <SS58_ADDRESS> --node-miner 4

Requirements are modest: 4 cores / 4 GB RAM covers comfortable scanning. Invalid payout addresses refuse to start — by design.

Community governance

OpenGov

Token holders steer the protocol through OpenGov referenda with conviction voting. Treasury spends and bounties pass through ranked tracks — from small tips to major initiatives.

The remaining upgrade authority (Prime) is deliberately narrow: runtime upgrades, cancelling referenda and rejecting treasury spends. Nothing else.
