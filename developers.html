METAMASK SETUP

Add Network to MetaMask

Execute this snippet in your dApp to request a MetaMask connection to Chain ID 32026.

wallet_addEthereumChain
window.ethereum.request({
  method: 'wallet_addEthereumChain',
  params: [{
    chainId: '0x7D1A',
    chainName: 'Numen Testnet',
    rpcUrls: ['https://rpc.numen-network.org'],
    nativeCurrency: {
      name: 'Numen',
      symbol: 'NMN',
      decimals: 18
    }
  }]
});
Web3 Integration

EVM Integration Code Snippets

viem / wagmi Chain Definition 
import { defineChain } from 'viem'

export const numenTestnet = defineChain({
  id: 32026,
  name: 'Numen Testnet',
  nativeCurrency: { name: 'Numen', symbol: 'NMN', decimals: 18 },
  rpcUrls: {
    default: {
      http: ['https://rpc.numen-network.org'],
    },
  },
})
ethers.js Provider Setup 
import { JsonRpcProvider } from 'ethers';

const provider = new JsonRpcProvider(
  'https://rpc.numen-network.org',
  { name: 'numen', chainId: 32026 }
);

const block = await provider.getBlock('latest');
console.log('Latest block:', block.number);
Smart Contract Deployment

Deploy with Foundry & Hardhat

FOUNDRY

Forge Deployment Command

Deploy compiled Solidity smart contracts directly via Foundry's forge CLI.

$ forge create --rpc-url https://rpc.numen-network.org --private-key <KEY> src/Counter.sol:Counter
HARDHAT

Hardhat Network Configuration

Add Numen network configuration to your hardhat.config.js file.

hardhat.config.js
networks: {
  numen: {
    url: "https://rpc.numen-network.org",
    chainId: 32026,
    accounts: [process.env.PRIVATE_KEY]
  }
}
Mining Protocol API

PoScan Mining RPC Endpoints

External mining rigs communicate with Numen full nodes using standard JSON-RPC calls.

RPC METHOD

mining_getTask

Fetches the current block header hash, target difficulty threshold, and seed derivation parameters for active mining.

RPC METHOD

mining_subscribeTask

Establishes a WebSocket subscription stream emitting real-time block header updates upon new proposal rounds.

RPC METHOD

mining_submitSeal

Submits a valid nonce and computed 23-dimension spectral hash seal to the local node for block seal propagation.

Example · Fetch Current Mining Task 
curl -X POST http://127.0.0.1:9944 \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "mining_getTask",
    "params": [],
    "id": 1
  }'

Mining RPC methods are served by full nodes on the local interface. Point external rigs at your own node endpoint — never expose mining RPC publicly.
